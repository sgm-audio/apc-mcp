# Contributing

The contributing guide has moved into the documentation set:

**[Development & contributing → docs/development.md](docs/development.md)**

It covers setup, `npm run check`, the repository layout, how to add a tool, code style (no shell strings, honest `isError` reporting) and the guarded release process.

Quick start: `npm ci && npm run check`. Please read [docs/security.md](docs/security.md) before touching input validation or path handling.
