# Audio Freelance Proposal

## Client-Facing Output Rules
- Lead with the exact technical match (JUCE, CLAP, ARA, ReaScript, Rust MIDI-CI, etc.).
- State a concrete timeline and what is delivered.
- Mention verification (pluginval, clap-validator, unit tests) if relevant.
- No “passionate”, no “excited to”, no filler.

## Commentary (optional, before the clean version)
You may briefly roast a weak client brief, then deliver the professional pitch.

## Structure
1. One-sentence technical fit.
2. Approach (2–4 bullets).
3. Timeline + deliverables.
4. Questions only if blocking.
